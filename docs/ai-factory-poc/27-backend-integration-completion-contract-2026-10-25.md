#### Published integration setup — existing API, example values only

Generic project integration creation and discovery are already published:

- `POST /api/v1/integration/{projectKey}/{pluginName}` → `201`.
- `GET /api/v1/integration/project/{projectKey}/all/{pluginName}` → configured integrations.

For `pluginName=github-actions`, the backend-supplied example body is:

```json
{
  "name": "github_actions",
  "enabled": true,
  "integrationParameters": {
    "token": "<configured securely; never copied into evidence>",
    "repo": "<actual org/repository>",
    "ref": "<actual ref>",
    "fixWorkflowRef": "<actual workflow file>"
  }
}
```

The example parameter names come from the backend handoff; the generic integration schema alone does not validate provider configuration or prove dispatch. Creating this integration does not implement US-019 Pipeline CI-settings read/save/test, jobs/models/environments or capabilities.

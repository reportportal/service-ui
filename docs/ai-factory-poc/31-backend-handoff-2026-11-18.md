# AI Factory backend handoff for Service UI

**November 18, 2026 · [EPMRPP-118192](https://jiraeu.epam.com/browse/EPMRPP-118192) · [bootcamp-prototype @ f84903940](https://github.com/reportportal/service-ui/commit/f84903940da4dcde688e4f1b3ef341ca2611bb79)**

The main open dependencies are server-side test case filtering by iteration, a plan-wide summary of Draft blockers, contracts for Automation, Re-run and Pipeline CI settings, and end-to-end verification with a real CI workflow and agent. Create, Grade, Upload and Stage Trace need agreed producer payloads. Auto-Ready settings, stage Retry, Pipeline name search and Quality Standard already have published APIs. The remaining frontend integration work and contract decisions are listed below.
